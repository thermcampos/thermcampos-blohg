About this blog
---------------

If you like what you see, here's more information for you. This blog
is a simple and easy to use CMS engine, that uses Git as backend, to 
store the content of the posts and pages. All the content is written 
using any text editor and reStructuredText with some custom directives.
No panel or UI. You can do everything from your terminal using git and vim.

This means there's no auth, database, or heavy stuff to care in PHP.
Blohg is built in Python on top of Flask, and Jinja2 for html rendering.
You can learn more about it here: https://github.com/thermcampos/blohg.
All the credit goes to Rafael Martins, the author of Blohg: https://rafaelmartins.com/
